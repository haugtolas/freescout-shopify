# Shopify

Shopify customer and orders in the FreeScout conversation sidebar, customer sync, clickable order numbers, Workflows and Tags integration.

- Configure it in **Manage > Settings > Shopify** (and per mailbox in the mailbox settings).
- Update it from **Manage > Modules** (Update button).

Full documentation and releases: https://github.com/haugtolas/freescout-shopify
